Introduction

Single-source domain generalization aims to learn medical image segmentation models from one labeled source domain that remain reliable on unseen domains. Because target-domain data are unavailable during training, existing methods commonly improve generalization by expanding source-domain variation, with recent approaches increasingly using adaptive or adversarial search to generate difficult samples. However, for dense segmentation, this strategy raises a supervision issue. A transformed image usually inherits the source annotation, even when a strong appearance change weakens the image evidence supporting that annotation. Consequently, a high-loss sample may either expose a meaningful acquisition vulnerability or provide unreliable dense supervision. We propose ACME, an Annotation-Compatible Model-Driven Exploration framework that separates these two cases. ACME learns model-sensitive directions in a bounded acquisition space and probes them at multiple strengths to identify difficult acquisition variations. The resulting candidates are then qualified using anatomical visibility, task-semantic stability, and spatial-content correspondence. Only candidates that satisfy these criteria inherit the source annotation, and the hardest admitted candidate is used for training. If no candidate is admitted, ACME reverts to the original source image. Experiments on fundus, cardiac MRI, polyp, and prostate MRI segmentation show consistent improvements over the compared domain-generalization methods across all four settings. Mechanism analysis reveals a clear trade-off between segmentation difficulty and annotation compatibility as acquisition strength increases. This trade-off motivates selecting hard samples only when the inherited supervision remains reliable.

02 / Method

Probe → Qualify → Learn

ACME separates the search for model failures from the decision to trust inherited supervision.

01

Probe

A learnable bank of eight directions combines ten bounded acquisition factors: brightness, contrast, gamma, channel response, saturation, illumination, and blur/sharpening. Three strengths (α ∈ {0.35, 0.65, 1.00}) expose different distances along each direction.

02

Qualify

Each candidate passes anatomical visibility and EMA-teacher prediction checks first. The hardest survivors are then verified by frozen self-supervised spatial features. Candidates that fail are excluded from dense supervision.

03

Learn

The hardest admitted candidate is paired with the original source image for segmentation training. If the admissible set is empty, ACME safely falls back to the source image.

Without model feedback, fixed and random directions do not reliably find the acquisition variations that expose the evolving segmenter.
